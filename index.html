검색 리서치 — 준비 중인 기능이에요

원고 주제와 관련된 최신 자료·경쟁사 콘텐츠·키워드를 자동으로 조사해주는 기능을 이 화면에 추가할 예정입니다. 어떤 방식(네이버 검색, 구글 검색, 특정 키워드 트렌드 등)으로 조사하면 좋을지 알려주시면 이어서 만들어드릴게요.

이 브라우저 세션에서 실행한 원고·이미지 생성 작업을 최신순으로 보여줍니다. 새로고침하면 초기화됩니다.

아직 기록된 작업이 없습니다.

생성된 이미지

      

      

    

  


  
  

    

      자동으로 되는 부분: 인물 페르소나 탭에서 BEFORE·AFTER 이미지를 순서대로 생성하면, 두 이미지를 자동으로 합성하고 발행 순서에도 자동으로 넣어줘요(클릭 필요 없음). 제품 실사 이미지도 생성하면 바로 보관함에 담겨요. 원본 비포/애프터는 참고용으로 보관함에는 남지만 발행 순서에서는 기본적으로 빠집니다.

      필요할 때만 손으로: 순서를 바꾸거나 빼고 싶은 이미지가 있으면 아래 "발행 순서" 목록에서 체크·화살표로 조정하고, 완성되면 "번호 매겨 ZIP 다운로드"만 누르면 돼요. 실제 네이버 발행 자동화(크롤링)는 이 ZIP/매니페스트를 읽어서 그 순서대로 첨부하는 별도 스크립트에서 처리합니다.

비포/애프터 수동 합성 — 직접 업로드한 이미지용 (자동 생성 흐름에서는 필요 없음)

발행 순서 · 번호 매기기

      

      
이 글에 실제로 쓸 이미지만 체크하고, 화살표로 순서를 정하면 번호가 자동으로 매겨져요. 이 번호 순서대로 크롤링(자동 발행) 쪽에서 이미지를 첨부하면 됩니다.

      
보관함에서 이미지를 담으면 여기에 순서 목록이 생겨요.

      

      

        
        
      

    


    

      

        
이 글 내보내기 — naver-publisher 스크립트용

      

      
"새 글 준비" 탭에서 가장 최근에 생성한 원고 + 위 발행 순서에 포함된 이미지를 post.txt + images/ 구조로 묶은 ZIP 하나로 내려받아요. 압축을 풀어서 naver-publisher/posts/ 아래에 그대로 넣으면 바로 publish.js·publish-rotate.js에서 쓸 수 있어요.

      
아직 이번 세션에서 생성한 원고가 없어요. 새 글 준비 탭에서 원고를 먼저 생성해주세요.

      

        
      

    

  


  
  

    

      여기서는 계정 목록·하루 발행 한도만 관리해요. 실제 네이버 로그인은 이 화면(브라우저 웹페이지)에서는 절대 하지 않습니다 — 비밀번호를 다루는 코드를 만들지 않기로 했었죠.
      대신 대표님 컴퓨터에서 naver-publisher/login.js를 계정마다 딱 한 번 실행해서 직접 로그인하면 그 로그인 세션만 저장되고, 이후 발행은 그 세션을 재사용해요.
      아래 목록은 "어떤 계정이 있고, 계정마다 하루에 몇 건까지 발행할지"를 정리해서 accounts.json으로 내보내는 용도예요 — 내보낸 파일을 naver-publisher 폴더에 그대로 덮어쓰면 됩니다.
