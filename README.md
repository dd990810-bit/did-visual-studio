# 비주얼 프롬프트 스튜디오 — 웹사이트 버전 (비밀번호로 본인만 접속)

인물 페르소나 / 제품 실사 이미지 생성 / 블로그 원고 작성을 **하나의 웹사이트**에서 처리하고,
**비밀번호를 아는 사람만** 들어올 수 있게 잠가둔 버전입니다. 사이트에 접속하면 제일 먼저
비밀번호 입력 화면이 뜨고, 맞는 비밀번호를 넣어야 안쪽 화면(원고 작성, 이미지 생성)을 볼 수 있습니다.

프롬프트를 복사해서 다른 도구(Nano Banana Pro, GPT Image 등)에 붙여넣을 필요 없이, 이 사이트 안에서 바로:

- 원고 작성 버튼 → Claude(Anthropic API)가 실제 원고를 써서 화면에 보여줌
- "이미지 생성" 버튼 → OpenAI(gpt-image-1)가 실제 제품 사진을 생성해서 화면에 보여주고 다운로드까지 가능

폴더 구성:

```
webapp/
  public/
    index.html         ← 화면 (프론트엔드)
    login.html          ← 비밀번호 입력 화면
  functions/
    _middleware.js       ← 모든 요청을 가로채서 로그인 여부를 확인 (사이트 잠금장치)
    api/
      login.js            ← 비밀번호 확인
      logout.js           ← 로그아웃
      write.js            ← 원고 작성 API (Anthropic 호출, 서버에서만 실행됨)
      image.js             ← 이미지 생성 API (OpenAI 호출, 서버에서만 실행됨)
      health.js             ← API 키/비밀번호가 설정됐는지 확인하는 상태 체크
```

`functions/`는 **Cloudflare Pages Functions**라는 기능으로, 별도의 서버를 직접 운영하지 않아도
API 키와 비밀번호를 안전하게(브라우저에 노출되지 않게) 보관하면서 Anthropic/OpenAI를 호출해주는
역할을 합니다. Cloudflare는 무료 요금제로도 충분히 운영 가능합니다(요청 100,000회/일 무료).

---

## 먼저 솔직하게 말씀드릴게요

지난번에 이 코드만 압축파일로 보내드렸을 때 "사이트를 만들어달라고 했는데 이게 뭐냐"고
하신 게 맞는 지적이었어요. 죄송합니다. 이 코드는 사이트를 "만드는 재료"이고, 인터넷 주소로
실제로 띄우려면(=배포) 어딘가에 올리는 과정이 한 번 필요합니다.

이 배포 과정에서 딱 하나, 제가 대신해 드릴 수 없는 단계가 있습니다: **무료 호스팅 계정을
직접 만드는 것**(이메일 인증만 하면 되고 카드 등록도 필요 없어요). 이건 AI가 대신 계정을 만들거나
비밀번호를 입력하는 걸 금지하는 보안 규칙 때문에, 편의가 아니라 안전을 위해 막혀 있는 부분이에요.
그 외 업로드, 설정, 이번에 추가한 비밀번호 잠금까지는 전부 이미 다 만들어서 아래 절차대로만
따라오시면 됩니다 (개발 지식 전혀 필요 없어요).

## 1. 배포 방법 (계정 없어도 10분이면 됩니다)

### 1) Cloudflare 무료 계정 만들기
1. https://dash.cloudflare.com/sign-up 접속 → 이메일로 무료 가입 (카드 등록 불필요)
2. 로그인 후 왼쪽 메뉴에서 **Workers & Pages** 클릭

### 2) 이 폴더를 Pages 프로젝트로 업로드
1. **Workers & Pages** 화면에서 **Create application** → **Pages** 탭 → **Upload assets** 선택
2. 프로젝트 이름 입력 (예: `did-visual-studio`) → **Create project**
3. 이 `webapp` 폴더 "안의" 내용(`public`, `functions` 등)을 드래그 앤 드롭으로 업로드
   - 주의: `webapp` 폴더 자체가 아니라, 그 안의 `public`과 `functions`가 최상위에 오도록 올려주세요.
4. 업로드 후 자동으로 배포가 시작되고, 완료되면 `https://did-visual-studio.pages.dev` 같은 주소가 발급됩니다.

> 참고: 위 방식(Upload assets)은 가장 빠르지만, 파일을 수정할 때마다 다시 업로드해야 합니다.
> 나중에 GitHub 저장소와 연결하면 코드를 고칠 때마다 자동 배포되도록 만들 수도 있습니다 (원하시면 이어서 도와드릴게요).

### 3) 키·비밀번호 등록 (가장 중요한 단계)
배포된 프로젝트 화면에서 **Settings** 탭 → **Environment variables**(또는 **Variables and Secrets**)로 이동해서,
아래 세 개를 **Secret**으로 추가하세요:

| 이름 | 값 | 용도 |
|---|---|---|
| `SITE_PASSWORD` | 원하시는 비밀번호 아무거나 (예: 팀 내부에서만 아는 문구) | 이 사이트에 들어올 수 있는 사람을 결정하는 잠금 비밀번호 |
| `ANTHROPIC_API_KEY` | Anthropic Console에서 발급 (https://console.anthropic.com/settings/keys) | 원고 작성용 |
| `OPENAI_API_KEY` | OpenAI 플랫폼에서 발급 (https://platform.openai.com/api-keys) | 이미지 생성용 |

저장 후, 화면에서 **재배포(Retry deployment / Redeploy)**를 한 번 눌러야 새 값이 적용됩니다.

이 세 값은 브라우저에 절대 노출되지 않고 Cloudflare 서버 안에만 안전하게 보관되기 때문에,
저 역시 값을 볼 수도 없고 대신 입력해드릴 수도 없습니다(API 키·비밀번호는 AI가 직접
입력하지 못하도록 되어 있는 항목이라, 이 칸만은 디드 님이 직접 붙여넣어 주셔야 해요).

### 4) 완료
발급된 주소(`https://xxxx.pages.dev`)로 접속하면, 제일 먼저 비밀번호 입력 화면(`login.html`)이
뜹니다. 3번에서 정하신 `SITE_PASSWORD`를 입력하면 그 다음부터는 본인 브라우저에서 30일간
다시 안 물어봅니다. 이 주소 하나만 즐겨찾기 해두면 로그인이나 별도 프로그램 설치 없이
비밀번호를 아는 사람만 웹사이트처럼 바로 사용할 수 있습니다.

사이트 상단에 "API 키가 설정되지 않았어요" 같은 경고가 뜨면 3번 단계가 아직 안 된 것이니
확인해주세요.

## 2. 비용 안내 (솔직하게 말씀드립니다)

- **Cloudflare Pages**: 무료 요금제로 충분합니다. (하루 100,000 요청까지 무료, 이 정도로는 절대 초과하지 않습니다.)
- **원고 작성(Claude/Anthropic API)**: 기존에 쓰시던 claude.ai 채팅과 별개로, API 호출량만큼 종량 과금됩니다. 원고 1건당 비용은 매우 낮은 편(모델에 따라 다르지만 보통 건당 몇 원~수십 원 수준)이지만, 이제는 "무료"가 아니라 실제 API 사용료가 발생한다는 점은 분명히 알고 계셔야 합니다.
- **이미지 생성(OpenAI gpt-image-1)**: 기존에 ChatGPT/Nano Banana Pro 등에서 수동으로 생성하시던 것과 동일하게, 이미지 1장당 비용이 발생합니다(해상도에 따라 다름).

즉, "하나의 웹사이트에서 다 처리"되는 편리함을 얻는 대신, 원고 작성 기능이 (기존 클로드 아티팩트의
무료 사용량 대신) 실제 API 사용료가 드는 유료 기능으로 바뀌는 점이 유일한 트레이드오프입니다.
사용량이 걱정되시면 Anthropic/OpenAI 콘솔에서 사용 한도(월별 예산 알림)를 설정해두는 걸 추천드립니다.

## 3. 기존 "비주얼 프롬프트 스튜디오" 아티팩트와의 관계

지금까지 쓰시던 claude.ai 아티팩트 버전(프롬프트 텍스트만 생성해서 다른 곳에 붙여넣던 방식)은
그대로 남아있고 계속 쓰실 수 있습니다. 이 웹사이트 버전은 그걸 대체하는 것이 아니라,
"프롬프트 생성 → 복사 → 다른 이미지 생성기에 붙여넣기"라는 수작업 단계를 없애고
그 자리에서 바로 결과물(원고, 이미지)까지 받아보실 수 있게 만든 상위 버전입니다.
두 개를 병행하다가, 웹사이트 버전이 익숙해지시면 아티팩트 버전은 그때 정리하셔도 됩니다.
